## ✨ Progetti

### 🚀 Console Comparator
 applicazione React per la ricerca, filtro e confronto di
console di gioco, con gestione dei preferiti e visualizzazione dettagliata.
Interfaccia responsive e codice ottimizzato per facilità di manutenzione e
scalabilità.

### 🚀 Boolroad
progetto di gruppo realizzato con React e Vite, che permette la
gestione di viaggi e partecipanti tramite un interfaccia responsive e una
navigazione fluida supportata da React Router e Bootstrap.

### 🚀 Boolshop
 e commerce sviluppato in team con React, integrando routing
dinamico, gestione dello stato globale e notifiche. Ho contribuito alla
progettazione e sviluppo delle funzionalità chiave, creando un interfaccia
responsive e ottimizzata con Bootstrap
